RGX / Roadmap

Roadmap

The current RGX development plan, clearly separating implemented features from planned work.

On this pagev0.1 — Format foundation ✅v0.2 — Streaming, chunking & dedup ✅v0.3 — Private archives & benchmark ✅v0.4 — Hardening & selective accessLater

v0.1 — Format foundation ✅

  • Custom RGX container
  • Zstandard compression + store fallback
  • BLAKE3 per-file integrity
  • Pack / extract / list / info / verify CLI
  • Path-safety checks and CI

v0.2 — Streaming, chunking & dedup ✅

  • Streaming source reads
  • Content-defined chunking
  • Archive-wide BLAKE3 chunk identity
  • Chunk-level deduplication
  • Per-chunk and per-file integrity verification

v0.3 — Private archives & benchmark ✅

  • Argon2id + XChaCha20-Poly1305 Private Mode
  • Encrypted file names, paths, chunk IDs and metadata
  • Wrong-password and tamper tests
  • Built-in ZIP benchmark + optional 7-Zip comparison

v0.4 — Hardening & selective access

  • Remove temporary plaintext inner container
  • Seekable encrypted I/O
  • Random-access authenticated decryption
  • Footer index and fast lookup
  • More cryptographic test vectors and fuzzing

Later

  • Adaptive compression profiles
  • Snapshots and incremental archives
  • Recovery/parity blocks
  • Public-key recipient encryption after a dedicated security design
  • Signatures, mounting, GUI and release packages
