Quick start

RGX is currently developed as a Rust CLI. The command surface is intentionally small.

rgx pack ./project project.rgx
rgx pack ./project project.rgx --private
rgx list project.rgx
rgx info project.rgx
rgx verify project.rgx
rgx extract project.rgx ./restore

Private Mode

With --private, the complete inner RGX container is encrypted. The password is prompted without echo and confirmed while packing.

rgx pack ./project project.rgx --private
Important

v0.3 is experimental and has not been independently audited. Read the security model before sensitive use.

Benchmark

The benchmark compares RGX with a built-in ZIP/Deflate baseline. An installed 7-Zip executable is included automatically when available.

rgx benchmark ./project
rgx benchmark ./project --private

Automation

Passwords are not accepted as literal command-line arguments. Automation may use a named environment variable.

RGX_PASSWORD='…' rgx pack ./project project.rgx --private --password-env RGX_PASSWORD
