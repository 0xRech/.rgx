Quick start

rgx pack ./project project.rgx
rgx list project.rgx
rgx info project.rgx
rgx verify project.rgx
rgx extract project.rgx ./restore

Recipient Mode

Create a dedicated RGX identity and encrypt the archive for its public key. RGX does not reuse arbitrary SSH private keys; the default location only lives under ~/.ssh for convenience.

rgx keygen
rgx pack ./project project-recipient.rgx --recipient ~/.ssh/id_rgx.pub
rgx extract project-recipient.rgx ./restore

With the matching unprotected ~/.ssh/id_rgx, RGX unlocks automatically without an archive password. Multiple --recipient arguments and --password-fallback are supported.

Protected identities

rgx keygen --protect

Protected private identity files use Argon2id + XChaCha20-Poly1305. The identity passphrase is separate from an optional archive password fallback.

Detached Ed25519 signatures

rgx sign backup.rgx --identity ~/.ssh/id_rgx
rgx verify-signature backup.rgx backup.rgx.sig --public-key ~/.ssh/id_rgx.pub

rgx verify checks archive structure and integrity. verify-signature additionally checks that the exact archive bytes were signed by the holder of the matching RGX private identity.

Password Private Mode

--private remains available as the password-based mode.

rgx pack ./project project-private.rgx --private
Important

v0.5.0-alpha1 is experimental and has not received an independent cryptographic audit.

Selective access

rgx find project.rgx "report"
rgx cat project.rgx docs/report.txt
rgx extract project.rgx ./restore --path docs

Seekable Private and Recipient streams support list, find, cat, verify and selective extraction without materializing a complete decrypted temporary inner archive.

Benchmark

The built-in benchmark compares RGX with ZIP/Deflate and optionally an installed 7-Zip. The current Recipient implementation snapshot is documented separately.

rgx benchmark ./project
rgx benchmark ./project --private

Automation

Passwords are not accepted as plaintext CLI arguments. Named environment variables are available for Private Mode, password fallback and protected identities.

RGX_PASSWORD='…' rgx pack ./project private.rgx --private --password-env RGX_PASSWORD
RGX_KEY_PASSWORD='…' rgx verify recipient.rgx --identity ~/.ssh/id_rgx
