Design principles

Three priorities.
One format.

Storage efficiency, privacy and integrity should reinforce each other instead of being separate afterthoughts.

01 / COMPACT

Find repetition. Store it once.

Content-defined chunking re-synchronizes after inserted or removed bytes. Identical chunks across files are referenced instead of stored again.

02 / PRIVATE

Encrypt the structure, not just the files.

Private Mode protects the complete inner container — including paths, file names, chunk identifiers and metadata — using authenticated encryption.

v0.4 hardening

Private Mode streams packing output directly into authenticated frames and decrypts them on demand through a seekable reader. It no longer materializes a complete temporary plaintext inner container.

Questions

Important context.

Does RGX already replace ZIP or 7-Zip?

Not yet. RGX is functional, but still an experimental pre-1.0 format.

Are duplicate files restored during extraction?

Yes. Deduplication only saves payload inside the archive. Every original file and path is reconstructed.

Can I send a private .rgx to another device?

Yes. The archive is portable. The other device needs RGX and the correct password. Recipient keys are planned as the next security feature.
