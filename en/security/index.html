Security

Threat model, cryptographic profile, metadata exposure and known limitations of RGX v0.4.0-alpha.2.

On this pageStatusCryptographic profileProtected informationPrivate-mode hardeningReporting vulnerabilities

Status

RGX v0.4.0-alpha.2 is experimental software. Private Mode uses established cryptographic primitives, but has not undergone an independent audit and should not yet be treated as a mature replacement for long-established tools in high-risk environments.

Cryptographic profile

Protected information

Private Mode encrypts the complete inner container. Without the password, file contents, names, paths, directory structure, chunk IDs, chunk equality relationships and inner statistics are not directly exposed.

The outer envelope still reveals that the file is private RGX, the public KDF parameters and approximate encrypted size.

Private-mode hardening

Streaming instead of a temporary plaintext file

v0.4 streams packing output directly into authenticated encryption frames and decrypts frames on demand through a seekable reader. A complete plaintext inner container is no longer materialized as a temporary file. Individual requested chunks still exist briefly in process memory while being processed or extracted.

Reporting vulnerabilities

Please do not publish exploit details in a public issue first. Use GitHub private vulnerability reporting if it is enabled for the repository.
