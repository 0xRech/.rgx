Zwei Schichten

RGX v0.3 besteht aus dem inneren v0.2-Archivformat und optional der privaten v0.3-Hülle. Die Hülle authentifiziert und verschlüsselt den kompletten inneren Container.

Innerer RGX-v0.2-Container

RecordPurpose
RGX\016-byte archive header
CHNKUnique chunk payload + BLAKE3 identity + compression metadata
FILEPath, file digest and ordered chunk references
DIREDirectory path
RGXFFooter statistics and consistency checks

Reference chunking: 64-byte rolling window · 64 KiB minimum · ~256 KiB target · 1 MiB maximum.

Private v0.3-Hülle

FieldValue

AADEnvelope header + frame header

Nonce & Authentisierung

nonce = 16-byte random prefix || 8-byte little-endian frame sequence
AAD = 60-byte envelope header || 24-byte frame header

Sequences start at zero, increase by exactly one, and exactly one authenticated final frame is required. Trailing bytes are rejected.

Kompatibilität

Plain RGX verwendet weiterhin inneres Format 0.2. Private RGX verwendet Hülle 0.3 um einen vollständigen 0.2-Innencontainer. Vor 1.0 können Formatrevisionen absichtlich inkompatibel sein.
