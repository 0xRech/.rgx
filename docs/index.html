Dokumentation

CLI, Private Mode, Verifikation und Benchmarking der aktuellen RGX-v0.3-Referenzimplementierung.

Auf dieser SeiteSchnellstartPrivate ModeBenchmarkAutomatisierung

Schnellstart

RGX wird aktuell als Rust-CLI entwickelt. Die Kernbefehle sind bewusst klein gehalten.

rgx pack ./project project.rgx
rgx pack ./project project.rgx --private
rgx list project.rgx
rgx info project.rgx
rgx verify project.rgx
rgx extract project.rgx ./restore

Private Mode

Mit --private wird der komplette innere RGX-Container verschlüsselt. Das Passwort wird verdeckt abgefragt und beim Packen bestätigt.

rgx pack ./project project.rgx --private
Wichtig

v0.3 ist experimentell und noch nicht unabhängig auditiert. Lies vor sensibler Nutzung das Security-Modell.

Benchmark

Der Benchmark vergleicht RGX mit einer eingebauten ZIP/Deflate-Basis. Ein installiertes 7-Zip wird optional automatisch ergänzt.

rgx benchmark ./project
rgx benchmark ./project --private

Automatisierung

Passwörter werden nicht als Klartext-CLI-Argument akzeptiert. Für Automatisierung kann eine benannte Umgebungsvariable verwendet werden.

RGX_PASSWORD='…' rgx pack ./project project.rgx --private --password-env RGX_PASSWORD
